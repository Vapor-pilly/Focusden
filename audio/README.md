# Local audio provenance

All sounds are played locally. The current sounds are original procedural synthesis, not natural recordings, live piano performances, or live guitar recordings. No downloaded recordings or existing songs are used.

| File | Description and source |
| --- | --- |
| `rain.wav` | 32-second continuous stereo study rain: broad, non-tonal, even volume, softened high frequencies. Replaces isolated drops. Generated by `tools/make_soft_rain.py`. |
| `piano.wav` | 64-second original stereo melody using damped string harmonics, soft attacks, and short room reflections. Generated by `tools/make_soft_piano.py`; replaces the tide menu entry. |
| `forest.wav` | Original synthesized forest/wind ambience, retained. |
| `water.wav` | Original short water-interaction effect, retained. |
| `complete.wav` | Original distinct cycle-completion cue, retained. |
| `page-turn.wav` | Approximately 0.58 seconds of original synthesized paper brushing. Generated by `tools/prepare_book.py`; automatic and manual turns respect the scene-effects switch. |
| `guitar-C.wav` through `guitar-B.wav` | Seven original 2.8-second decaying plucked-string notes: C D E F G A B. Generated by `tools/prepare_guitar.py`. |
| `waves.wav` | Historical tide file, retained for compatibility; no longer offered in the menu or overwritten by the current generator. |

`tools/make_audio.py` rebuilds the basic audio, study rain, and piano. The book atlas/paper sound and guitar assets/notes have separate generation scripts. Background audio loops, supports volume changes and stopping, and never overlaps a previously selected background track. Scene effects and the cycle cue are separate from background playback. Playback begins after user interaction; browser autoplay restrictions still apply.
