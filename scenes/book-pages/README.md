前三次翻页起点约为 0、2.2、4.4 秒，提取前 6.6 秒，30 帧每秒，共 198 帧，保存为三张本地 WebP 图集。自动翻页间隔保持约 2.2 秒。

点击书本额外翻一页；若当前正在翻页则排队完成，不中途截断。不点击书本时继续原节奏，点击空白或按钮不翻页。自动和点击翻页都触发本地纸张音效，受「场景互动音效」开关控制。浏览器首次未交互时可能禁止自动声音，点击页面后即可播放。
