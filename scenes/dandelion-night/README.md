# 月夜风愿 · 第四个互动素材

参考 `互动场景原素材/蒲公英.mp4` 的细密绒毛形态和闪亮种子，以实时绘制重新制作，原视频保留不动。

深蓝渐变夜空与右上角大月亮，下方为高低错落的一排蒲公英：左侧密集，向右间距逐渐扩大，不再只有一朵巨大的蒲公英。

- 点击花球：该朵花上部分种子脱离，带着细小绒毛和闪烁微光，随风向右上方飘散。
- 点击空白处不会凭空产生种子；点击按钮和弹窗不触发飘散。
- 脱落位置约 11–17 秒后开始补回，方便反复互动；漂浮种子数量有限制，不会无限堆积。
- 使用已有场景轮换与备份；切走后停止动画并清理输入监听。

`scene.js` 保存场景登记及花朵布局，`renderer.js` 保存实时绘制与互动，`preview.png` 为实际预览。

预览：http://127.0.0.1:8765/?preview=dandelion-night

第三个素材「星光雨窗」仍保存在 `../rain-window/`，另有 Git 标签 `rain-window-v1`。
