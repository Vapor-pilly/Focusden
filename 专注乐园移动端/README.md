# 专注乐园 · iPhone 移动端

这是独立于电脑版的完整 PWA 网页运行包，包含八套互动场景、全部本地音频、番茄计时、个人统计、场景解锁与收藏、导入/导出备份。手机安装图标为咖啡杯与三个音符。

**文件包已就绪，但尚未发布到 HTTPS 地址，也没有安装到任何 iPhone。ZIP 本身不是 iPhone 安装程序。**

详细步骤见 [iPhone安装说明.md](iPhone安装说明.md)。建议 iOS 17 或更新系统，使用 Safari 正常模式。

- `index.html / app.js / style.css`：完整应用源文件。
- `mobile.css / mobile.js`：移动布局、安全区和离线准备状态。
- `scenes/`：八套场景代码与必要图像素材。
- `audio/`：所有本地声音，无需外部音频服务。
- `manifest.webmanifest / sw.js / assets/icon-*.png`：桌面安装、离线缓存和图标。
- `asset-list.json / 版本信息.json`：完整运行资源清单与版本。
- `server.cjs`：电脑预览辅助服务，仅监听 `127.0.0.1:8787`。
- `预览/`：实际手机尺寸模拟截图，不影响运行。
- `专注乐园移动端.zip`：可传送的完整文件包，解压后再部署静态文件。

约 14.4 MB 原始运行资源；没有复制 Git 仓库、临时工具、原始大视频或个人浏览器数据。原始素材已用于生成场景，运行不依赖源视频。完整版运行代码都在本文件夹中，HTTPS 静态托管即可提供安装入口；不需要账户、数据库、API 或 Node 后端。

电脑版运行代码未修改，仍使用原来的地址。手机与电脑的浏览器数据互相独立，通过 JSON 备份迁移，不能自动同步。

重新生成：在电脑版项目根目录运行 `python tools/build_mobile.py`（需要 Pillow），然后 `python tools/package_mobile.py`。本移动端是单独副本；生成脚本会覆盖其受管理的源文件，修改前请保留副本。
