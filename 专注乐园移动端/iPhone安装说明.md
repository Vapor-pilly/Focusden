# iPhone 安装与离线使用

## 先明确文件包与安装的区别

本包是可部署的 PWA 网页应用，不是签名 IPA。仅把 ZIP 通过微信、AirDrop 或“文件”App 传到手机，不能直接完成主屏幕安装和离线缓存。iPhone 安装需要先有一个可从 Safari 访问的 HTTPS 地址。

当前交付状态：文件包和自动测试已完成；尚未提供或发布 HTTPS 安装地址。文件里的 `127.0.0.1:8787` 只供当前电脑预览，不是手机可访问的安装地址。电脑的普通 HTTP 局域网 IP 地址同样不能作为本包的离线安装方案。

## 第一次安装

1. 把本文件夹内的静态运行文件部署到你使用的 HTTPS 静态网站。`index.html` 放入口目录，保持 `assets/`、`audio/`、`scenes/` 等相对路径不变；`sw.js` 应与 `index.html` 同级，不要把不存在的 WAV/JS 路径重写成 HTML。
2. iPhone 用 Safari 打开 HTTPS 地址，进入底部「我的」，等待「离线资源已就绪」。首次需要约 14.4 MB 运行资源的下载；期间保持网络。
3. 在 Safari 中点「分享」→「添加到主屏幕」；如果出现「作为 Web App 打开」，开启后点「添加」。
4. **从主屏幕的新图标再次打开，保持联网，进入「我的」再次确认「离线资源已就绪」，再导入备份。** 主屏幕 App 与 Safari 的数据环境可能分开，不能只在 Safari 里缓存好就假定桌面 App 一定已缓存。
5. 开启飞行模式，重新从图标打开，尝试切换已解锁场景、操作舷窗和播放轻雨。完成这一步才算你这台 iPhone 的离线验收通过。

## 从电脑迁移记录

1. 电脑版「我的」→「导出备份」。把 JSON 文件发送到手机并保存到“文件”。
2. 从手机主屏幕图标打开专注乐园，「我的」→「导入备份」，选择该 JSON。
3. 检查累计周期、专注时间、已解锁与收藏。恢复后计时暂停，手动开始即可。
4. 电脑与手机不会自动同步。若要把手机进度带回电脑，反向导出/导入；导入会用选中的备份替换当前记录，不会合并两台设备的累计数据。

## 日常使用与边界

- 首次完整缓存之后，场景、音频和应用从设备本地缓存运行。联网重新打开时，浏览器可能检查同源版本更新；没有第三方字体、CDN、分析或音频请求。
- 正常刷新或重启保留记录。请从同一主屏幕图标使用；改域名/端口、更换浏览器、清除网站数据或删除 App 可能改变或移除本地数据。系统储存回收也不是应用能绝对控制的，重要记录请定期导出备份。
- 页面仍存活时，移动版使用实际经过时间补算后台间隔；若系统已经终止页面，重开会从最后保存的进度暂停恢复。**PWA 无法保证 iOS 锁屏/后台时准时发出番茄完成声，也不能代替原生系统闹钟。** 前台计时和点击音效可正常使用，首次声音请由手动点击开启。
- 遮光帘可以按住把手上下拖；鱼群按住引导，雨窗拖动擦雾，书本/蒲公英/紫藤点击互动，琴弦点击或轻划发声。
- 「我的」里的「重新准备离线资源」可在联网时修复缺失缓存，不会清除专注记录。

## 电脑预览

在本文件夹运行 `node server.cjs`，打开 `http://127.0.0.1:8787/`。可用浏览器设备工具模拟 iPhone。该地址仅用于电脑本机预览；建议使用独立的浏览器测试资料，避免把预览数据当作手机数据。
